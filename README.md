## 📖 Sobre o Projeto

Este projeto foi criado como material de estudo para aprender os **comandos básicos do Git** e o fluxo de trabalho essencial para versionamento de código. A página HTML estilizada com CSS apresenta de forma clara e objetiva os principais comandos e como utilizá-los no dia a dia do desenvolvimento.

---

## 🎯 O que aprendi com este projeto

### ✅ Conceitos teóricos

| Conceito | O que entendi |
|----------|---------------|
| **Git** | Sistema de controle de versão distribuído que rastreia mudanças no código |
| **Repositório** | Pasta onde o Git monitora as versões dos arquivos |
| **Commit** | "Fotografia" do estado atual dos arquivos, com uma mensagem descritiva |
| **Staging area** | Área intermediária onde os arquivos ficam prontos para serem commitados |
| **Repositório remoto** | Local na nuvem (ex: GitHub) para compartilhar código |

### ✅ Comandos essenciais aprendidos

| Comando | O que faz |
|---------|-----------|
| `git init` | Inicia um novo repositório Git na pasta atual |
| `git status` | Mostra o estado dos arquivos (modificados, adicionados, etc.) |
| `git add .` | Adiciona todos os arquivos modificados à área de staging |
| `git commit -m "mensagem"` | Salva as mudanças com uma mensagem descritiva |
| `git push` | Envia os commits locais para o repositório remoto (GitHub) |
| `git pull` | Baixa as mudanças do repositório remoto |
