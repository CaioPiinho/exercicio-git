📚 Aula Básica de Git

🔹 O que é Git?

Git é um sistema de controle de versão usado para gerenciar código.

🔹 Comandos principais

  • git init → inicia um repositório
  • git status → mostra o estado
  • git add . → adiciona arquivos
  • git commit -m "mensagem" → salva mudanças
  • git push → envia pro GitHub

🔹 Fluxo básico

  1. Criar arquivos
  2. Adicionar com git add
  3. Commitar
  4. Enviar para o GitHub
